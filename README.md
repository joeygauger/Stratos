# Corporate Intelligence Web App

This is a static, installable PWA prototype.

## Included
- Watchlist
- Company overview
- 5-year financial view
- DCF sensitivity
- Scenario Lab
- Reverse Scenario
- iPad/iPhone PWA manifest and service worker

## Use on iPad
A PWA must be served over HTTPS (or localhost) for full install/offline behavior.
Upload the folder to a static host such as GitHub Pages, Netlify, Cloudflare Pages, or Vercel.
Then open the HTTPS URL in Safari and choose Share → Add to Home Screen.

## Important
The current app uses demo data and simplified formulas. It is the interactive UI/prototype layer, not yet the live public-data ingestion backend.
